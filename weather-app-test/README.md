# Weather App Test

A simple weather app demo built with HTML, CSS, and JavaScript. This project demonstrates a basic web app structure and the use of front-end files to display weather-related content.

## About

A weather app where the user can enter a city and get a weather forecast. Key features include:

- Change temperature display between Celsius and Fahrenheit.
- View either a 5-day forecast or a 24-hour forecast.
- Save favorites for quick access.

## Purpose

This repository was created to practice new skills using GitHub Copilot in VS Code, while building a simple weather app.
